# 出勤管家 - 完整系統說明文件

## 📋 系統簡介

這是一個基於 **LINE Login** 和 **Google Apps Script** 開發的企業級考勤薪資管理系統。使用者可以透過 LINE 帳號登入，使用手機 GPS 進行打卡，並完成請假、加班申請等人事作業。所有資料即時儲存在 Google 試算表中，方便管理與查詢。

---

## ✨ 主要功能

### 基礎功能
- **LINE 帳號登入**  
  透過 LINE Login 認證，確保使用者身份。未來預計加入 Google Login 認證，使用者可選擇登入方式。

- **GPS 定位打卡**  
  利用瀏覽器地理位置 API 取得經緯度，進行上班與下班打卡。支援多地點打卡驗證。

- **補打卡功能**  
  可手動選擇日期時間，補登過去的打卡紀錄，需經管理員審核。

- **異常紀錄檢視**  
  自動檢查並標示出異常的打卡紀錄，方便使用者修正。

- **即時訊息提示**  
  打卡成功或失敗都會有即時訊息回饋。

### 進階功能

#### 管理員功能
- **地點管理**：新增、編輯打卡地點與容許範圍
- **補打卡審核**：審核員工補打卡申請
- **請假審核**：審核員工請假申請
- **加班審核**：審核員工加班申請
- **全員出勤報表**：匯出全體員工出勤資料
- **薪資計算**：支援三種薪資計算情境（飼料廠司機、食品廠移工、管理部行政）

#### 員工功能
- **定位查看**：查看當前位置與可打卡範圍
- **加班申請**：線上提交加班申請
- **請假申請**：線上提交請假申請（支援15種假別，小時制計算）
- **個人出勤報表**：匯出個人出勤記錄
- **薪資查詢**：查看個人薪資明細

#### LINE 即時通知
系統會透過 LINE 發送以下通知：
- 忘記上班打卡提醒（每日上午檢查）
- 忘記下班打卡提醒（每日上午檢查）
- 補打卡審核結果（核准/拒絕）
- 請假審核結果（核准/拒絕）
- 加班審核結果（核准/拒絕）

### 多國語系支援
根據瀏覽器語言自動切換介面語系（繁體中文、日文、英文、韓文、越南文、印尼文）- 尚未完善

## 🗄️ 系統架構

### 前端 (Frontend)
- **HTML**：頁面結構
- **CSS**：使用 Flexbox 進行排版，確保 RWD 效果
- **JavaScript**：
  - 使用者介面互動
  - 呼叫後端 API 進行資料交換
  - 使用 `localStorage` 儲存登入狀態
  - 利用 `navigator.geolocation` 取得 GPS 資訊
  - 實現 i18n 多國語系翻譯功能

### 後端 (Backend)
- **Google Apps Script**：
  - 作為後端伺服器處理 API 請求
  - 實現 LINE Login OAuth 2.0 流程
  - 將打卡資料寫入 Google 試算表
  - 處理資料庫查詢與異常檢查邏輯
  - 實現薪資計算引擎（三種情境）
  - 整合 LINE Messaging API 發送通知

## 🔄 系統資料流程整合

### 打卡流程：
```
員工打卡 → 驗證地點 → 寫入「打卡紀錄」
         ↓
    補打卡申請 → 寫入「補打卡申請」→ 管理員審核
                                    ↓ (核准)
                            寫回「打卡紀錄」+ LINE 通知
```

### 請假流程：
```
員工請假 → 計算工時 → 寫入「請假紀錄」(PENDING)
                              ↓
                        管理員審核
                              ↓ (核准)
                    扣除「員工假期額度」→ 更新狀態(APPROVED) + LINE 通知
```

### 加班流程：
```
員工加班申請 → 寫入「加班申請」(pending)
                      ↓
                管理員審核
                      ↓ (核准)
            更新狀態(approved) + LINE 通知
                      ↓
            可轉為「加班補休假」額度
```

### 薪資計算流程：
```
calculateMonthlySalary()
```

## 💰 三種薪資計算情境

### 情況一：飼料廠司機（月薪制-不定時工作）
**特點：**
- 基本薪資：投保薪資底薪
- 加班費：固定 $200/小時
- 月休補薪：應休6天，未休補 $1,500/天
- 未休假補薪：按日薪計算
- 請假扣款：病假半薪、事假全薪（小時制）

**使用的 Sheets：**
- 員工薪資設定
- 打卡紀錄
- 加班申請
- 請假紀錄
- 未休假記錄
- 月休記錄
- 月薪資記錄

---

### 情況二：食品廠移工（時薪制-標準工時）
**特點：**
- 基本薪資：時薪 × 工作時數
- 固定津貼：底薪（大）、工作津貼
- 加班費規則：
  - 延長工時：底薪/30/8 × 1.34 × 時數（前2h）
  - 休息日：底薪/30/8 × 時數（前8h）
  - 國定假日：底薪/30/8 × 時數（前8h）
- 請假扣款：
  - 病假：底薪/30/8 × 小時數 / 2
  - 事假：底薪/30/8 × 小時數
- 未休假補薪：底薪/30 × 未休天數
- 其他扣款：代扣所得稅、仲介服務費、健檢費、代辦費

**使用的 Sheets：**
- 員工薪資設定
- 打卡紀錄
- 加班申請
- 請假紀錄
- 未休假記錄
- 月薪資記錄

---

### 情況三：管理部行政（月薪制-標準工時）
**特點：**
- 基本薪資：固定月薪
- 固定津貼：職務加給、伙食費、交通補助等
- 加班費規則（含分鐘四捨五入）：
  - 延長工時（前2h）：底薪/30/8 × 1.34 × 時數
  - 延長工時（後2h）：底薪/30/8 × 1.67 × 時數
  - 休息日：前2h (×1.34)、3-8h (×1.67)、9h起 (×2.67)
  - 國定假日：底薪/30 × 天數（出勤1小時也算1天）
- 請假扣款：
  - 病假：底薪/30/8 × 小時數 / 2
  - 事假：底薪/30/8 × 小時數
- 未休假補薪：底薪/30 × 未休天數
- 不固定獎金：中秋、過年跟特殊計劃推動的短期津貼

**分鐘四捨五入規則：**
- 滿20分鐘算半小時（0.5h）
- 滿50分鐘算1小時（1.0h）

**使用的 Sheets：**
- 員工薪資設定
- 打卡紀錄
- 加班申請
- 請假紀錄
- 未休假記錄
- 不固定獎金記錄
- 月薪資記錄

## 🚀 如何設定與部署

### 1. Google Apps Script 設定
1. 複製後端 Google Apps Script 程式碼
2. 在 Google 雲端硬碟中建立一個新的 Google 試算表
3. 在「擴充功能」中開啟 Apps Script
4. 將程式碼貼上，並在「專案屬性」中設定 **LINE Channel ID** 和 **Channel Secret**
5. 建立所有必要的工作表（執行 `initializeAllSheets()` 函數）
6. 將專案發佈為一個網頁應用程式 (Web App)

### 2. LINE Developers 設定
1. 登入 **LINE Developers** 後台，建立 LINE Login 頻道
2. 建立 LINE Messaging API 頻道（用於發送通知）
3. 在「基本設定」中，記下 **Channel ID**、**Channel Secret** 和 **Channel Access Token**
4. 在「網頁應用程式」的 **回呼網址 (Callback URL)** 中，設定部署網址

### 3. 前端部署
1. 複製前端程式碼 (`index.html`, `style.css`, `script.js`, `config.js` 等)
2. 在 `config.js` 中，設定 `apiUrl` 和 `redirectUrl` 為你的 Google Apps Script URL
3. 將所有前端檔案部署到靜態網站託管服務（GitHub Pages 或 Vercel）

## ⚠️ 重要注意事項

1. **Session 工作表**：每次檢查都會自動延期，避免頻繁登入
2. **補打卡申請**：核准後會自動寫入打卡紀錄，不需手動複製
3. **假期餘額**：使用小時制（1天 = 8小時），審核時自動扣除
4. **地點管理**：支援多地點，自動選擇最近的合法範圍
5. **資料備份**：遷移工具會自動備份舊資料
6. **銀行代碼**：必須使用文字格式（前綴單引號 '007）避免自動轉換
7. **年月欄位**：建議使用文字格式（前綴單引號 '2026-01）避免轉成日期
8. **請假時間**：必須是整點（09:00, 14:00），不可有分鐘數
9. **管理員權限**：目前暫時開放所有人使用管理員功能，方便測試
